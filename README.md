# Tekisasu Graphics

Tekisasu Graphics is a private modification of [Aseprite](https://github.com/aseprite/aseprite), a pixel art tool and sprite editor.

![Project Screenshot](profile/screenshot.png "Tekisasu Graphics screenshot")

## About

This project focuses on customizing Aseprite to better integrate with the Tekisasu Engine pipeline. The primary modifications center around customized default export options that are optimized for game development workflows in the Tekisasu Engine.

## Availability

In accordance with the original Aseprite project's licensing requirements:

- ✅ **Source code** is available to the public through this organization's repositories
- ❌ **Binaries** (compiled executables) are NOT publicly distributed

This restriction is required by Aseprite's license, which prohibits the public distribution of compiled binaries for Aseprite or its derivatives.

## Building from Source

If you wish to use Tekisasu Graphics, you must build it from source. Please refer to the main repository for build instructions and requirements.
